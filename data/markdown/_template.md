الغرض: ما الذي تساعد به هذه الحزمة الوكيل؟ ما المهمة الكتابية أو الأسلوبية التي تحسنها؟

## بطاقة سريعة
- نوع المصدر: بلاغة / معجم / شعر / نحو-أسلوب / مرجع عام / غير ذلك
- مستوى التغطية: كتاب كامل / باب / فصل / مقتطف / قصيدة / مجموعة أبيات / مدخل معجمي
- درجة التحرير: استخلاص محافظ / تلخيص تحريري / إعادة تنظيم مع شواهد / غير ذلك
- مناسب لمهام: تحرير / إعادة صياغة / كتابة تعليمية / كتابة إقناعية / تحليل أسلوبي / توليد شواهد

## طريقة استعمال هذا القالب
- ابدأ دائمًا بالنواة الإلزامية.
- لا تُبقِ كل الأقسام الاختيارية في الملف النهائي؛ احذف ما لا يخدم المادة فعلًا.
- إذا كان المصدر غنيًا، فأضف وحدات متعددة بدل ضغط الفائدة في قائمة قصيرة واحدة.
- لا تملأ أي عنوان بحشو عام غير مردود إلى المصدر.

## ملاحظات حذف/إبقاء قبل الاعتماد
