# مواصفة حزم Markdown الموجهة للوكلاء

## الهدف

تحويل المعرفة المستفادة من المصادر إلى ملفات Markdown سهلة القراءة لوكلاء الذكاء الاصطناعي، مع الحفاظ على الارتباط بالمصادر الأصلية.

## مبادئ التصميم

- قصيرة نسبيًا وقابلة للمسح السريع
- مقسمة بعناوين واضحة
- تفصل بين القواعد المستخلصة وبين الشواهد المنقولة
- تذكر المصادر بوضوح
- تخدم مهمة الكتابة العربية الفصحى والبليغة مباشرة

## أنواع الملفات المتوقعة

- مفردات وتراكيب فصيحة
- أساليب تعبير
- مبادئ بلاغية
- أخطاء شائعة وصيغ بديلة
- شواهد شعرية ونثرية
- أدلة أسلوبية موجزة للوكلاء

## البنية المقترحة

1. عنوان الملف
2. الغرض العملي
3. قواعد أو ملاحظات مختصرة
4. أمثلة جيدة
5. أخطاء شائعة أو صيغ أضعف
6. شواهد من المصادر
7. قائمة المصادر

## شرط التتبع

كل ملف Markdown يجب أن يذكر معرفات المصادر التي بُني منها.
