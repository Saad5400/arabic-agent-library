# الخطة التنفيذية الرئيسية لمكتبة البلاغة والفصاحة للوكيل العربي

> هذه هي الخطة التشغيلية المرجعية للمشروع. أي تشغيل لاحق يجب أن ينطلق منها، ويحدّث مربعاتها عند الإنجاز الفعلي.

## الهدف الرئيسي

بناء مكتبة عربية مصدرية مكتملة بالقدر العملي، تمكّن الوكيل من كتابة العربية الفصحى على هدى المعجم، والنحو، والأسلوب، والمرجع، والشاهد؛ بحيث تكون كل فائدة نهائية قابلة للرد إلى مصدر حقيقي محفوظ في المستودع.

## تعريف الإنجاز النهائي

لا نعدّ المشروع قد بلغ هدفه الرئيسي إلا إذا تحققت الشروط الآتية كلها:

- [x] كل مصدر مسجّل في `data/registry/sources.json` صار له مسار عمل واضح ومكتمل أو مستبعد صراحةً بسبب مبرر موثق.
- [x] كل مصدر بحالة `synthesized` يملك عناصره الثلاثة كاملة:
  - [x] ملف raw واضح
  - [x] ملف text منظف/عملي
  - [x] ملف Markdown واحد أو أكثر بعدد مبرر
- [x] لا تبقى مصادر foundation الأساسية ناقصة في طبقات المعاجم والنحو/الأسلوب.
- [x] كل تشغيل جديد يلتزم بقاعدة الحجم: تقريبًا ملف Markdown واحد لكل ~20 صفحة مصدرية، لا تفتيت زائد.
- [x] السجل يمر دائمًا على:
  - [x] `python3 scripts/registry_tool.py lint`
  - [x] `python3 scripts/registry_tool.py check-duplicates`
- [x] توجد مذكرة تشغيل واضحة تكفي أي وكيل ليستلم المشروع ويعرف: ماذا اكتمل، ماذا بقي، وما الترتيب الصحيح للتنفيذ.
